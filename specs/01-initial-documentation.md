# PR 01 — საწყისი დოკუმენტაცია

## დავალება

კოდის დაწყებამდე პროექტის საწყისი გეგმის, Pull Request-ების თანმიმდევრობისა და repository-ში მუშაობის წესების აღწერა.

## Scope

- მთავარი `SPEC.md` ფაილის შექმნა;
- PR-ებისთვის ცალკე specification ფაილების მომზადება;
- `AGENTS.md` ფაილის დამატება;
- README-ში დოკუმენტაციის ბმულების დამატება.

ამ PR-ში application code და infrastructure არ შედის.

## შედეგი

- შეიქმნა მთავარი `SPEC.md`;
- შეიქმნა პირველი PR-ის specification;
- შეიქმნა მეორე PR-ის საწყისი specification;
- დაემატა `AGENTS.md`;
- README-ში დაემატა დოკუმენტაციაზე გადასასვლელი ბმულები.

## ცვლილებები საწყის გეგმასთან შედარებით

თავდაპირველად ყველა Pull Request-ის აღწერა ერთ `SPEC.md` ფაილში იყო დაგეგმილი. ეს მიდგომა შეიცვალა, რადგან დოკუმენტი ზედმეტად დიდი და რთულად წასაკითხი გამოვიდა.

ამის ნაცვლად მთავარი `SPEC.md` დარჩა ინდექსად, ხოლო თითოეული PR-ის დავალება და შედეგი ცალკე ფაილში ინახება.
