# PR 02 — პროექტის მომზადება

## დავალება

NestJS backend-ის, Angular frontend-ისა და Docker გარემოს საწყისი სტრუქტურის მომზადება.

## Scope

- NestJS პროექტის შექმნა;
- Angular პროექტის შექმნა;
- Docker Compose-ის დამატება;
- PostgreSQL-ის დამატება;
- Elasticsearch-ის დამატება;
- RabbitMQ-ის დამატება;
- backend-ის მარტივი health endpoint;
- თითოეული service-ის გაშვების შემოწმება.

ამ PR-ში Backfill, Incremental Sync და Gate-ების ლოგიკა არ შედის.

## წარმატების კრიტერიუმი

- Backend წარმატებით იბილდება;
- Frontend წარმატებით იბილდება;
- Docker Compose უშვებს საჭირო service-ებს;
- API-ის health endpoint წარმატებულ პასუხს აბრუნებს.

## შედეგი

ჯერ არ არის შესრულებული.

## ცვლილებები საწყის გეგმასთან შედარებით
