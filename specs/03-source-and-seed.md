# PR 03 — Source მონაცემები და Seed

## დავალება

PostgreSQL-ში საწყისი მონაცემების სტრუქტურის შექმნა და configurable რაოდენობის სატესტო მომხმარებლების გენერაცია.

## Scope

- PostgreSQL migration-ების მომზადება;
- `customers` ცხრილის შექმნა;
- customer-ის `version` ველის დამატება;
- ცვლილებების შესანახად `change_log` ცხრილის შექმნა;
- საჭირო index-ების დამატება;
- მონაცემების batch-ებად გენერაცია;
- `make seed` ბრძანების დამატება;
- seed რაოდენობის parameter-ით მართვა.

Seed-ის გაშვების მაგალითი:

    make seed COUNT=100000

დიდი რაოდენობის მონაცემი ერთდროულად მეხსიერებაში არ უნდა ჩაიტვირთოს. მომხმარებლები ნაწილებად უნდა შეიქმნას და PostgreSQL-ში batch-ებად ჩაიწეროს.

ამ PR-ში მონაცემების Elasticsearch-სა და RabbitMQ-ში გაგზავნა არ შედის.

## მონაცემების საწყისი სტრუქტურა

პირველ ეტაპზე სისტემა დაამუშავებს ერთ entity-ს — `customer`.

Customer-ის საწყისი ველები:

- `id`;
- `name`;
- `email`;
- `status`;
- `attributes`;
- `version`;
- `created_at`;
- `updated_at`.

`change_log` შეინახავს:

- `id`;
- `entity_id`;
- `entity_version`;
- `operation`;
- `payload`;
- `created_at`.

## წარმატების კრიტერიუმები

- [ ] Database migration წარმატებით სრულდება;
- [ ] `customers` და `change_log` ცხრილები იქმნება;
- [ ] Seed ქმნის მითითებული რაოდენობის customer-ს;
- [ ] დიდი რაოდენობის მონაცემი batch-ებად მუშავდება;
- [ ] `make seed` განმეორებით გაშვებადია;
- [ ] შექმნილი ჩანაწერების რაოდენობა SQL query-ით მოწმდება.
