# PR 09 — G4: ნაწილობრივი Batch და DLQ

## დავალება

Batch-ში ერთი event-ის მუდმივი შეცდომის დროს დანარჩენი სწორი event-ების დამუშავება უნდა გაგრძელდეს.

Retry-ის ამოწურვის შემდეგ გაფუჭებული event DLQ-ში უნდა გადავიდეს.

## Scope

- transient და permanent შეცდომების განსხვავება;
- თითოეული event-ის ცალკე შედეგის შენახვა;
- წარმატებული event-ების checkpoint;
- retry-ის ამოწურვის დამუშავება;
- RabbitMQ Dead Letter Queue;
- failed event-ისა და error-ის შენახვა;
- batch-ის დანარჩენი event-ების გაგრძელება;
- `make verify-g4` ავტომატური შემოწმება.

## წარმატების კრიტერიუმები

- [ ] ერთი გაფუჭებული event მთელ batch-ს არ აჩერებს;
- [ ] სწორი event-ები ორივე destination-ში აღწევს;
- [ ] retry-ის ამოწურვის შემდეგ event DLQ-ში გადადის;
- [ ] failed event-ის მიზეზი ინახება;
- [ ] checkpoint მონაცემის დაკარგვის გარეშე ახლდება;
- [ ] `make verify-g4` წარმატებით სრულდება;
- [ ] G1, G2 და G3 კვლავ მუშაობს.
